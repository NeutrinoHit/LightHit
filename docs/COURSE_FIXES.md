## Исправлено в cache.py

- `exact_first_order=True` теперь запрещён для направленной приёмки. Прежняя
  реализация неверно умножала изотропный первый порядок на A(прямого направления).
  Для постоянной приёмки опция сохранена с правильным масштабом.
- Значимые коэффициенты приёмки выше степени кэша больше не теряются молча.
- Диапазоны BandedResponseCache обязаны иметь одну среду и одинаковую сетку ω.
- Проверены NaN, формы, направление на точном прямом луче и световая нормировка.
- `radius_chunk` ограничивает размер удерживаемой Bessel-таблицы. При нескольких
  блоках используются временные NPY-файлы и по одному отображению в память;
  при одном блоке всё остаётся в RAM. Метаданные различают RAM блока, объём
  дискового scratch и выходных массивов. Это не ограничитель полного RSS процесса.
- Сплайн строится один раз для нужных степеней/частоты; `clear_interpolation_cache`
  явно сбрасывает его после изменения массива moments пользователем.
- Заряд из многочастотного кэша обрабатывает только ω=0.
- Добавлена необязательная `radial_phase='flight'`: выделение exp(iωr/v) перед
  радиальной интерполяцией. По умолчанию `'none'` сохраняет прежние результаты.
  Наличие демодуляции не заменяет уточнения радиальных узлов.
- Исправлены направленная геометрия и граница диапазонов в validation_report.

Метод углового решения, сетки существующего SolverSettings, первая координатная
квадратура и readout не изменены.

## Новые файлы, не новый производственный маршрут

`src/lighthit/experimental/` содержит проверяемые, ограниченные по постановке
прототипы: прямой постоянный черенковский сегмент; стационарное собственное
разложение P_N; положительный оболочечный Monte Carlo.

Существующее ядро `angular.py` не переписано. Экспериментальные модули
подключаются явным импортом и не меняют режим PointGreenSolver.

## Что ещё нельзя объявлять готовым

Общий направленный источник вместе с направленным/конечным ОМ; полноценный
G4-конвертер и массовое применение; сертификация временной радиальной таблицы;
дальняя асимптотика произвольного временного источника. Переиспользование
сохранённых частот не решает эти задачи автоматически.

Для курса выбраны короткие вычисления. Все ошибки и отрицательные бины
сохраняются. Численная проверка выбранных примеров не гарантирует ту же ошибку
при произвольных г, расстояниях и угловых профилях.
