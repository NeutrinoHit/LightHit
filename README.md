# LightHit

Time-dependent light transport and detector response.

Первая поставка: функция Грина для мгновенной монохромной точечной вспышки
и изотропного точечного приёмника. Поддержаны **заданное направление одного
фотона** и **изотропное испускание одного фотона**. Среда однородная,
неограниченная; фазовая функция Henyey–Greenstein (HG).

## Что возвращает расчёт

`PointGreenSolver.solve` вычисляет комплексный спектр отклика на единицу
эффективной площади, м⁻². Нулевая частота даёт интегральный сигнал («заряд»).
`result.readout` даёт интегралы по временным бинам, м⁻²; деление на ширину
бина даёт среднюю скорость регистрации, м⁻²·нс⁻¹.

Эффективность регистрации равна 1, чувствительность одинакова по всем
направлениям. Площадь не подменяется единицей без указания размерности.
Умножение на малую эффективную площадь A даёт ожидаемое число фотонов.
Модель не содержит поверхности ОМ, первого входа в неё или затенения.

Направленная дельта-вспышка и точечный приёмник на её точном прямом луче
дают сингулярный ответ. Такой запрос отклоняется. Угловая окрестность,
считаемая сингулярной в API: cos(theta) >= 1 - 1e-12. Для таких геометрий
понадобится конечная апертура либо конечное угловое распределение источника.
В демонстрации угол равен 60°, прямой свет равен нулю, полный сигнал рассеян.
Для изотропной вспышки прямой свет — временная дельта-функция с конечным
интегралом; интегралы по бинам вычисляются точно.

## Установка в вашем чистом checkout

Требуется Python 3.11 или новее. Команды выполняются из `~/Projects/LightHit`:

```bash
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e '.[notebook,dev]'
```

## Первый расчёт без Jupyter

```bash
python -m lighthit --config examples/point-green.toml \
  --output .build/point-green --plots
```

Результаты:

- `.build/point-green/spectrum.npz`: частоты и компоненты 0, 1, ≥2;
- `.build/point-green/profiles.npz`: бины без размытия и с заданным readout;
- `.build/point-green/report.json`: параметры, заряд, замеры и диагностики;
- `.build/point-green/figures/`: отдельные рисунки профилей и спектра.

Заряд без построения временного спектра:

```bash
python -m lighthit --charge-only --repeat 3 --output .build/charge
```

Быстрый обзор и более строгая численная настройка:

```bash
python -m lighthit --preset quick --output .build/quick --plots
python -m lighthit --preset refined --output .build/refined --plots
python scripts/compare_runs.py .build/point-green .build/refined
```

Для сопоставимых замеров можно ограничить потоки численных библиотек:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
  python -m lighthit --repeat 3 --output .build/benchmark
```

`--repeat` повторяет сам расчёт, не загрузку сохранённого результата. В отчёте
сохраняются все времена. Первый выпуск не использует дисковый транспортный кэш.
Внутри одного вызова `solve` угловое решение общее для всех точек наблюдения.

## Python API

```python
import numpy as np
from lighthit import PointGreenSolver, SolverSettings, synthetic_medium

medium = synthetic_medium()  # ТЕСТОВЫЕ числа; не байкальская калибровка.
solver = PointGreenSolver(medium, SolverSettings())
omega = np.linspace(0.0, 1.2, 241)  # рад/нс; обязательно включить 0 для заряда.
result = solver.solve(
    omega,
    displacement_m=[17.32050807568877, 0.0, 10.0],  # приёмник минус источник, м
    direction=[0.0, 0.0, 1.0],
)
print(result.charge_per_m2)
print(result.timings_s)
front = result.front_time_ns[0]
edges = np.arange(front - 30, front + 651, 2.0)
raw = result.readout(edges, sigma_ns=0.0)
measured = result.readout(edges, sigma_ns=3.0)
```

Чтобы задать изотропную вспышку, передайте `direction=None`. Для нескольких
приёмников передайте `displacement_m` формы `(D,3)`. Время испускания задаётся
`emission_time_ns`; число испущенных фотонов — `photons`.
Нормаль точечному изотропному детектору не нужна.

## Приватная вода

В дистрибутиве **нет** приватных оптических массивов, коэффициентов ОМ, файлов
событий, приватных выходных спектров или зависимости от старого `baikal-rte`.
Адаптер читает известный из прежнего проекта интерфейс `BaikalWater.py`.
Он не импортирует `OpticalModule.py`: эффективность здесь равна 1.

```python
from lighthit.providers import load_bgvd_water

medium = load_bgvd_water(
    "/полный/локальный/путь/к/bgvd-model",
    wavelength_nm=450.0,
    g=0.9,  # Явно выбранная HG-модель; не извлекается из коэффициентов воды.
)
```

Путь может указывать на checkout либо на его каталог `bgvd_model`.
Если приватный пакет установлен, аргумент пути можно опустить.

Для CLI скопируйте конфигурацию в `.local-inputs/private-green.toml` и замените
только раздел среды:

```toml
[medium]
kind = "bgvd_water"
path = "/полный/локальный/путь/к/bgvd-model"
wavelength_nm = 450.0
g = 0.9
```

Дальше запускайте с `--config .local-inputs/private-green.toml`. Все результаты
оставляйте в `.build/`. В `report.json` и NPZ записываются фактически
использованные коэффициенты — эти выходные файлы для приватной среды
нельзя публиковать. Адаптер проверен на искусственном двойнике интерфейса;
с реальным приватным пакетом в этой поставке не запускался.

При g=0.9 потребуется отдельный скан степени HG: настройки для g=0.7 не
являются проверкой g=0.9. Например, начните сравнение L=64 и 96, затем уточняйте
до сходимости; заранее заданной гарантии точности этих двух значений нет.

## Что именно решается и где искать формулы

Математическое изложение: [docs/point-green.qmd](docs/point-green.qmd).

| Файл | Содержание |
|---|---|
| `src/lighthit/medium.py` | Параметры одного спектрального узла, м и нс |
| `src/lighthit/angular.py` | Трёхдиагональная сопряжённая задача, точный свободный хвост |
| `src/lighthit/single.py` | Координатный первый порядок с полной HG-функцией |
| `src/lighthit/green.py` | Радиальное обращение и общий спектр 0+1+≥2 |
| `src/lighthit/readout.py` | Бины и независимое аппаратное размытие |
| `src/lighthit/providers.py` | Локальный приватный поставщик воды |
| `tests/` | Независимые матричные, аналитические и геометрические проверки |

Все числа столкновений включены. **Порядки ≥2 используют коэффициенты HG
только до L**, а точный первый порядок использует полную HG-функцию.
Это явно заданная составная аппроксимация полного HG-ответа; при L→∞ её
различие с полной HG исчезает. Свободный угловой перенос не обрезается на L:
его бесконечный хвост исключён аналитически. Пространственное угловое
обращение имеет свою независимую степень J.

Также конечны область и квадратура по k, частотная полоса и шаг частоты.
`quick`, `balanced`, `refined` меняют несколько пространственных/угловых
настроек; они не устанавливают математическую границу ошибки.
На точном световом фронте неразмытые бины могут осциллировать. Код сохраняет
отрицательные значения и массу до фронта; не обрезает и не перенормирует их.
Компоненты 0 и 1 интегрируются по времени напрямую, поэтому их фронты не
зависят от выбранного частотного cutoff. Обратное Фурье применяется к ≥2.

## Что ещё не входит в первый модуль

Конечная сфера ОМ, реальные приёмка/PDE, конусы и трековые сегменты, ливни,
спектральная свёртка, универсальный пространственный кэш, SVD/NUFFT,
GPU, граничные поверхности и неоднородная среда.
Измерения на тестовой воде не подтверждают точность на приватной оптике.

Источники математической конструкции и статус лицензии:
[PROVENANCE.md](PROVENANCE.md). Правообладатели и лицензия должны быть
согласованы до публикации исходников; эта поставка их не назначает.
