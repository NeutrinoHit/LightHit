# LightHit: исполняемый курс

Базовая версия: `3ba25b711408f65ed2511f4abe5fbb0ee0d4457c`.
Эта серия добавляется к существующему ноутбуку `01_point_green.ipynb`, не заменяя
его и не изменяя выводы прежних исследований. Все параметры открытые и
искусственные. Приватный провайдер не вызывается; доступ к интернету при расчёте
не требуется.

## Запуск

Из корня LightHit, после последовательного применения двух патчей:

```bash
source .venv/bin/activate
python -m pip install -e '.[notebook,accelerate,dev]'
python -m pytest -q
python -m jupyter lab notebooks/course
```

Открывайте файлы по порядку, выбирайте ядро установленного окружения и запускайте
Run All. Каждая тетрадь самостоятельна: результат предыдущей ей не требуется.
Первые ячейки печатают настоящий Python и платформу.

Для исполнения всей серии с HTML-выводом:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
  python scripts/run_course.py --output .build/course
```

Скрипт создаёт временное ядро **с тем же интерпретатором Python**, запускает
тетради в отдельных процессах, сохраняет исполненные `.ipynb`, HTML и
`execution.json`. Источники не перезаписываются. Первая компиляция Numba входит
во время соответствующей ячейки. Без Numba тетрадь 7 явно пропускает свой
Monte Carlo; для полного воспроизведения нужен extra `accelerate`.

```bash
python scripts/run_course.py --select 03_matrix_and_tail 08_stationary_modes
```

Сохранённый HTML содержит рисунки и выводы; редактирование параметров выполняется
в `.ipynb`. HTMLExporter использует MathJax для формул, поэтому просмотр формул
в автономном браузере зависит от доступности его JavaScript-ресурса.

## Последовательность

| Тетрадь | Математический результат | Что делает слушатель |
|---|---|---|
| 01_balance | RTE из баланса и нормировка отклика | Проверяет HG и сохранение числа, интегрирует баллистический импульс |
| 02_fourier_adjoint | `(D−V)h=1`, ответ как `h(s0)` | Проверяет проекции свободного ответа и объясняет отсутствие `m≠0` |
| 03_matrix_and_tail | Конечная M, обе правые части, свободный хвост | Собирает 4×4 матрицу, сверяет плотное решение и прогонку |
| 04_space_and_time | Пространственное обращение и временные бины | Считает спектр, показывает отрицательную массу и фронт без клиппинга |
| 05_cache_and_modules | Сохранённые мультиполи, произвольная геометрия | Считает новый источник без перестроения, выводит двухмоментную специализацию |
| 06_cones_and_segments | Точный азимутальный интеграл конуса и конечный шаг | Проверяет разбиение трека, перенос, поворот, временной сдвиг |
| 07_absorption_conditioning | Поглощение как экспоненциальное перевзвешивание | Сравнивает одинаковые пути при трёх μa, получает ковариационный критерий |
| 08_stationary_modes | Положительная модовая сумма вместо k-интеграла | Проверяет сходимость P_N, немонотонность направленности и дальнюю моду |

Одна тетрадь соответствует семинару; 3 и 4 можно разделить на два занятия.
Кодовые ячейки сгруппированы по математическим операциям, не по одной строке.
Задания в конце каждой тетради не выполняются автоматически за студента.
В базовых вычислениях есть `assert`-проверки нормировок и алгебры.

## Физический статус примеров

Основной `PointGreenSolver`: точные порядки 0 и 1 (полный HG), затем остаток ≥2
для оператора HG, усечённого на L. Свободный угловой хвост учтён аналитически.

`experimental.cone_segment`: баллистика конуса аналитическая; **оба рассеянных
вклада используют конечный L кэша**. Это учебный интегратор прямого постоянного
β-сегмента с изотропным точечным приёмником. Он не загружает G4, не моделирует
реальную сферу ОМ и не является быстрым вычислителем миллионов шагов.

`experimental.stationary_modes`: другой численный метод, усечение полного
углового пространства P_N. Он вычисляет только стационарные заряд и радиальный
ток изотропной вспышки. Ему нужна собственная сходимость по N. Он не использует
свободный хвост старого решателя и не возвращает временной профиль.

`experimental.shell_mc`: независимый положительный оцениватель скалярного потока
в сферической оболочке; это не счёт первого пересечения поверхности ОМ.
Конечная ширина оболочки и максимальная длина пути требуют уточнения отдельно
от статистической ошибки.

## Отчёт слушателя

Указывайте используемый коммит и фактические параметры. Для каждой проверки
сначала определите сравниваемую величину и нормировку ошибки, затем приведите
график/таблицу. Число тестов или гладкость графика не определяет физическую
точность. Разделяйте построение таблиц, их загрузку, новую геометрию и readout.
Не исправляйте отрицательные значения обрезанием или перенормировкой.
